## 1. 为什么要保存到文件

列表和字典默认只存在于当前进程的内存中。程序退出后，变量会消失；文件则保存在磁盘上，下次启动仍能读取。

```python
scores = [{"name": "Ada", "score": 90}]
```

上面的 `scores` 只在程序运行期间存在。要跨运行保留它，需要把数据序列化成文件，例如：

```csv
name,score
Ada,90
```

## 2. 用 `with` 自动关闭文件

```python
with open("message.txt", "w", encoding="utf-8") as file:
    file.write("你好，CSV！\n")
```

离开 `with` 代码块后，文件会被关闭，即使块内发生异常也能正确释放资源。

常见模式：

| 模式 | 含义 | 文件不存在 | 文件已存在 |
| --- | --- | --- | --- |
| `"r"` | 只读 | 抛出 `FileNotFoundError` | 从开头读取 |
| `"w"` | 覆盖写 | 创建文件 | **先清空旧内容** |
| `"a"` | 追加写 | 创建文件 | 在末尾追加 |

成绩表要保存“当前完整状态”时可用 `"w"`；如果需要保留每次历史日志，才考虑 `"a"`。

## 3. 用 `DictWriter` 写 CSV

```python
import csv

records = [
    {"name": "Ada", "score": 90},
    {"name": "Lin", "score": 75},
]

with open("scores.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "score"])
    writer.writeheader()
    writer.writerows(records)
```

- `fieldnames` 决定列名与列顺序。
- `writeheader()` 写第一行表头。
- `writerows(records)` 写多条字典记录。
- 官方 `csv` 文档建议打开 CSV 文件时使用 `newline=""`，让模块统一处理换行。

## 4. 用 `DictReader` 读回数据

```python
with open("scores.csv", "r", encoding="utf-8", newline="") as file:
    reader = csv.DictReader(file)
    loaded = [
        {"name": row["name"], "score": int(row["score"])}
        for row in reader
    ]

print(loaded)
```

输出：

```text
[{'name': 'Ada', 'score': 90}, {'name': 'Lin', 'score': 75}]
```

`DictReader` 读到的字段值默认都是字符串，因此必须显式写 `int(row["score"])`，才能继续计算平均分。

## 5. 把保存与加载写成函数

```python
import csv

FIELDS = ["name", "score"]


def save_scores(path, records):
    with open(path, "w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        writer.writerows(records)


def load_scores(path):
    try:
        with open(path, "r", encoding="utf-8", newline="") as file:
            reader = csv.DictReader(file)
            return [
                {"name": row["name"], "score": int(row["score"])}
                for row in reader
            ]
    except FileNotFoundError:
        return []
```

```python
records = [{"name": "Ada", "score": 90}]
save_scores("scores.csv", records)
print(load_scores("scores.csv"))
```

输出：

```text
[{'name': 'Ada', 'score': 90}]
```

把文件操作封装成函数后，可以在临时目录中测试，不必依赖某个固定桌面路径。

## 6. 空数据也要写表头

`records = []` 时仍调用 `writeheader()`，文件内容会保留：

```csv
name,score
```

再次读取会得到空列表，而不是因为缺少列名导致 `row["name"]` 失败。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| `"w"` 会在旧内容后追加 | `"w"` 会先截断旧文件 | 要追加日志才用 `"a"` |
| 不写 `with` 也一定能完整落盘 | 未关闭文件可能尚未刷新全部内容 | 优先使用 `with` |
| CSV 读出的 `"90"` 已是整数 | 默认字段值是字符串 | 用 `int()` 转换 |
| 文件编码可省略 | 不同环境默认编码可能不同 | 文本显式写 `encoding="utf-8"` |
| CSV 文件不需要 `newline=""` | `csv` 模块需要统一处理换行 | 读写 CSV 时都写 `newline=""` |
| 空列表就什么都不写 | 缺少表头会让后续读取失去列名 | 始终写表头 |

<details><summary>查看答案</summary>
