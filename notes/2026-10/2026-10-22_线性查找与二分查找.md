## 1. 两种查找

线性查找可用于任意列表，从左到右首次命中就返回；最坏检查 n 项，时间 O(n)。二分查找要求数据按同一规则有序，每次检查中间项并排除一半，最坏 O(log n)。两者这里都只使用固定几个变量，额外空间 O(1)。

闭区间写法从 `low=0, high=len(values)-1` 开始，循环条件是 `low<=high`。目标更大时令 `low=mid+1`，更小时令 `high=mid-1`；必须跨过 mid，否则可能死循环。

Python 的 `bisect_left` 返回保持有序的左侧插入点，不直接判断是否命中。若要判定命中，还需检查返回位置是否在范围内且元素等于目标。

## 2. 可运行示例

保存为 `search_demo.py`，输入第一行升序且互异的整数，第二行目标。空行代表空列表。

```python
def linear_search(values, target):
    checks = 0
    for i, value in enumerate(values):
        checks += 1
        if value == target:
            return i, checks
    return -1, checks


def binary_search(values, target):
    low, high = 0, len(values) - 1
    checks = 0
    while low <= high:
        mid = (low + high) // 2
        checks += 1
        if values[mid] == target:
            return mid, checks
        if values[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1, checks


def main():
    values = [int(x) for x in input().split()]
    target = int(input())
    linear = linear_search(values, target)
    binary = binary_search(values, target)
    print("Linear:", *linear)
    print("Binary:", *binary)


if __name__ == "__main__":
    main()
```

正常输入 `10 20 30 40 50` 与目标 `40` 输出：

```text
Linear: 3 4
Binary: 3 2
```

空列表输出两种查找均为 `-1 0`。无序数据不得交给今天的二分函数；先排序会产生额外成本且可能改变原下标，不能偷偷改变题意。

## ⚠️ 易错点

| 错误 | 纠正 |
| --- | --- |
| 无序列表也按中间值排除一半 | 二分方向依赖有序前提 |
| `while low < high` 照抄 | 本文闭区间契约用 `low <= high` |
| 更新为 `low=mid` | 必须越过已检查的 mid |
| 把插入点当成命中 | `bisect_left` 还需范围与等值检查 |
