## 1. 先问：输入变大，工作增加多少？

一份有 n 条成绩的列表，n 就是本例输入规模。固定读取第一项（前提非空）不需要扫描其他项；逐项统计要检查 n 项；比较全部不同下标对要检查 n(n−1)/2 对。

Big O 描述渐近上界，不是精确秒数；入门题通常要求最紧的常见增长量级。本文按固定成本的整数比较、索引与算术计数，暂不分析超大整数位数成本。相同 O(n) 的实现仍可能有不同的实际耗时。

| 模式 | 本例次数 | 常见最紧量级 |
| --- | --- | --- |
| 非空列表固定下标读取 | 1 | O(1) |
| 完整扫描 | n | O(n) |
| 两次先后完整扫描 | 2n | O(n) |
| 所有 i<j 下标对 | n(n−1)/2 | O(n²) |
| 正整数反复整除 2，直到不超过 1 | floor(log2 n)，n≥1 | O(log n) |

对 n=0，减半循环规定执行0次，不对0取对数。n=1也无需减半。
n=4时下标对为3+2+1=6；n=8时为28。线性次数翻倍，成对次数增长更快。

## 2. 不要只数循环的数量

两个循环先后执行，成本相加；如果两层各跑 n 次并嵌套执行，才得到 n² 次。内层只执行固定3次时，即使嵌套也只是3n。带提前返回的查找实际次数取决于目标位置，最好检查1项，最坏检查n项；说最坏 O(n) 不等于每次都做n次。

## 3. 可运行示例

保存为 `growth_counter.py`，执行 `python3 growth_counter.py`。第一行是空格分隔整数成绩（空行代表空列表），第二行是整数目标；输入按约定提供。计数不使用真实个人资料。

```python
def find_count(scores, target):
    checks = 0
    for i, score in enumerate(scores):
        checks += 1
        if score == target:
            return i, checks
    return -1, checks


def growth_counts(n):
    if n < 0:
        raise ValueError("n must be nonnegative")
    linear = 0
    pairs = 0
    halves = 0
    for _ in range(n):
        linear += 1
    for i in range(n):
        for _ in range(i + 1, n):
            pairs += 1
    remaining = n
    while remaining > 1:
        remaining //= 2
        halves += 1
    return linear, pairs, halves


def main():
    scores = [int(part) for part in input().split()]
    target = int(input())
    index, checks = find_count(scores, target)
    linear, pairs, halves = growth_counts(len(scores))
    print(f"Index: {index}")
    print(f"Checks: {checks}")
    print(f"Counts: {linear} {pairs} {halves}")


if __name__ == "__main__":
    main()
```

正常输入：

```text
70 80 90 80
90
```

输出：

```text
Index: 2
Checks: 3
Counts: 4 6 2
```

第一行为空、第二行80时：

```text
Index: -1
Checks: 0
Counts: 0 0 0
```

单个0且目标0时输出下标0、检查1次、Counts为1 0 0。目标重复时返回首次位置，不必扫描剩余元素。

`growth_counts` 是三个独立实验的组合，不是优化查找的方法；其中成对循环使完整函数总体时间 O(n²)，额外空间 O(1)。`find_count` 最坏时间 O(n)，额外空间 O(1)。主程序还要创建输入列表，整体存储 O(n)；不要把函数额外空间和保存输入混为一谈。

## ⚠️ 易错点

| 误解 | 纠正 |
| --- | --- |
| 有两个for就是O(n²) | 看嵌套关系与各自次数 |
| O(n)代表n秒 | 它是增长量级，不是秒数 |
| 检查到目标就停，所以总是O(1) | 区分当前输入、最好与最坏情况 |
| 减半等于每次减1 | 16→8→4→2→1，共4步 |
| range(n)创建n项列表 | range对象不是完整列表，不要无故list(range(n)) |
