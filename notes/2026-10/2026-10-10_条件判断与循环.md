## 🧠 一、条件判断：让程序选择道路

### 1. 比较的结果是布尔值

```python
score = 86
print(score >= 60)
print(score == 100)
print(score != 0)
```

输出：

```text
True
False
True
```

常用比较符号：`>`、`>=`、`<`、`<=`、`==`、`!=`。

- `score = 86`：把 86 **赋值**给变量。
- `score == 86`：询问两边是否**相等**，结果是 `True` 或 `False`。

多个条件可以组合：

```python
score = 86
print(score >= 0 and score <= 100)
print(score < 0 or score > 100)
print(not score >= 60)
```

`and` 要求两边都为真；`or` 只要一边为真；`not` 把真假反转。Python 也允许 `0 <= score <= 100` 这种连写，含义是成绩同时不小于 0 且不大于 100。

### 2. `if / elif / else`：同一条链只走一个分支

```python
score = 86

if score >= 90:
    level = "A"
elif score >= 80:
    level = "B"
elif score >= 60:
    level = "C"
else:
    level = "F"

print(level)
```

输出：

```text
B
```

程序从上往下检查，遇到第一个为真的条件后就执行对应代码块，并跳过同一条链的其余分支。因此区间通常从高到低写。

如果把第一项写成 `score >= 60`，86 会立刻进入这一项，后面的 `>= 80`、`>= 90` 都没有机会执行。

### 3. 缩进不是装饰，而是结构

Python 通常用 4 个空格表示代码属于哪个代码块：

```python
score = 70
if score >= 60:
    print("Pass")
    print("继续保持")
print("统计结束")
```

前两个 `print` 属于 `if`；最后一个没有缩进，无论条件真假都会执行。不要在同一文件里混用 Tab 和空格。

## 🔁 二、循环：让一段代码重复执行

### 1. `for`：次数或对象已知

```python
for i in range(3):
    print(i)
```

输出：

```text
0
1
2
```

`range(3)` 产生 0、1、2，**不包含终点 3**。常见形式如下：

| 写法 | 产生的整数 |
| --- | --- |
| `range(4)` | `0, 1, 2, 3` |
| `range(1, 4)` | `1, 2, 3` |
| `range(1, 6, 2)` | `1, 3, 5` |
| `range(5, 1, -1)` | `5, 4, 3, 2` |

录入第 `i + 1` 位学生的成绩时，可以保留程序里的从零计数，同时给用户显示从一开始的编号：

```python
for i in range(3):
    score = float(input(f"第 {i + 1} 位成绩："))
    print(f"收到：{score}")
```

### 2. `while`：不知道要重复几次

`while` 会在每轮开始前检查条件：

```python
count = 3
while count > 0:
    print(count)
    count -= 1
print("Go!")
```

输出：

```text
3
2
1
Go!
```

如果忘记 `count -= 1`，条件会一直为真，形成死循环。终端里通常可以按 `Control + C` 停止正在运行的 Python 程序。

### 3. `break` 与 `continue`

```python
for number in range(1, 6):
    if number == 2:
        continue
    if number == 4:
        break
    print(number)
```

输出：

```text
1
3
```

- 遇到 2：`continue` 跳过本轮的 `print`，进入下一轮。
- 遇到 4：`break` 直接结束整个循环，所以 4 和 5 都不会打印。

## 💻 三、完整示例：循环录入并统计成绩

下面程序假设人数是非负整数、成绩输入能转换为数字。若成绩不在 0–100，会继续要求输入；非数字输入的异常处理放到 10 月 15 日学习。

```python
student_count = int(input("人数："))

total = 0.0
passed = 0
excellent = 0

for i in range(student_count):
    score = float(input(f"第 {i + 1} 位成绩："))

    while score < 0 or score > 100:
        score = float(input("成绩需在 0–100，请重新输入："))

    total += score

    if score >= 85:
        excellent += 1
        passed += 1
    elif score >= 60:
        passed += 1

if student_count == 0:
    print("暂无成绩")
else:
    average = total / student_count
    print(f"平均分：{average:.2f}")
    print(f"及格人数：{passed}")
    print(f"优秀人数：{excellent}")
```

输入：

```text
4
80
92
105
85
58
```

这里 `105` 无效，所以程序会额外读取 `85` 作为第 3 位的成绩；最后的有效成绩是 80、92、85、58。输出：

```text
平均分：78.75
及格人数：3
优秀人数：2
```

再测试边界：只输入人数 `0`，循环执行 0 次，输出 `暂无成绩`，也不会发生除以 0。

### 为什么优秀人数也要加入及格人数？

`if / elif` 中同一位学生只会进入一个分支。成绩 92 先满足 `score >= 85`，不会再进入 `elif score >= 60`，所以优秀分支里要同时执行 `passed += 1`。

另一种写法是用两个独立的 `if`：

```python
if score >= 60:
    passed += 1
if score >= 85:
    excellent += 1
```

这时两个条件会分别判断，92 会让两个计数都加一。两种写法都可以，但含义不同。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| `=` 用来判断相等 | `=` 是赋值，`==` 才比较 | `if score == 60:` |
| `elif` 会继续检查所有条件 | 同一条链只执行第一个真分支 | 区间通常从高到低 |
| 两个独立 `if` 等同于 `if/elif` | 独立 `if` 可能都执行 | 先决定条件是否互斥 |
| `range(1, 5)` 包含 5 | 终点不包含 | 实际是 1、2、3、4 |
| `while` 会自动改变变量 | 循环体必须让条件有机会变假 | 例如 `count -= 1` |
| `continue` 结束整个循环 | 它只跳过当前一轮 | 结束整个循环用 `break` |
| `break` 只跳过一行 | 它会离开当前最内层循环 | 后续轮次不再执行 |
| 空数据也能直接算平均值 | 分母可能为 0 | 先判断数量是否为 0 |
| 缩进只是为了好看 | 缩进决定代码块归属 | 同层保持 4 个空格 |

### 练习 2 · 修复死循环

下面程序希望输出 1、2、3，但会一直输出 1。只增加或修改一行来修复它。

```python
i = 1
while i <= 3:
    print(i)
```

<details>
<summary>查看参考答案</summary>

```python
i = 1
while i <= 3:
    print(i)
    i += 1
```

每轮都让 `i` 增加，最终 `i <= 3` 会变成假。

</details>

### 练习 3 · 统计偶数

输入一个非负整数 `n`，输出 1 到 `n`（包含 `n`）之间有多少个偶数。要求使用循环和条件，不直接使用 `n // 2`。

<details>
<summary>查看参考答案</summary>

```python
n = int(input())
count = 0

for number in range(1, n + 1):
    if number % 2 == 0:
        count += 1

print(count)
```

`n = 0` 时，`range(1, 1)` 为空，输出 0；`n = 5` 时输出 2。

</details>
