## 1. 把综合任务拆成五个已有职责

| 函数 | 输入 | 返回值或作用 |
| --- | --- | --- |
| `parse_score(text)` | 用户输入的字符串 | 合法整数成绩，或表示无效的 `None` |
| `save_records(path, records)` | 路径、字典列表 | 将表头与记录保存到 CSV；不返回统计结果 |
| `load_records(path)` | 文件路径 | 记录列表；把成绩字段恢复为 `int` |
| `summarize(records)` | 已加载的记录 | 数量、平均分、最高分字典 |
| `main()` | 组合流程 | 调用上述函数并负责显示结果 |

不要把“屏幕显示了正确平均分”直接当作持久化成功：如果统计的仍是原来的内存列表，即使保存函数没有正确写文件，也可能显示正确结果。应当先保存，再加载，再统计，并检查姓名、数量和数值是否保持。

## 2. 三个容易混淆的边界

`parse_score("0")` 应返回整数 `0`，不是 `None`。因此判断合法性用 `score is not None`，不能只写 `if score`。

默认设置的 `csv.DictReader` 读到的成绩字段是字符串。例如 `"80"` 需要先用 `int(...)` 转换，才能用于数值计算。`DictWriter.writeheader()` 写列名；即使记录列表为空，也应保留表头。

空账本有 0 条记录，但没有定义好的平均分和最高分。这里返回 `None`，显示时用 `N/A`；不能把“没有数据”假装成“平均分是 0”。

## 3. 可独立运行的综合示例

在一个**新建的空测试目录**保存为 `gradebook_demo.py`。示例会创建或覆盖该目录下的 `gradebook_demo.csv`，不要使用个人账本路径。终端运行 `python3 gradebook_demo.py`。

```python
import csv

FIELDS = ["name", "score"]


def parse_score(text):
    try:
        score = int(text)
    except ValueError:
        return None
    if not 0 <= score <= 100:
        return None
    return score


def save_records(path, records):
    with open(path, "w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        writer.writerows(records)


def load_records(path):
    try:
        with open(path, "r", encoding="utf-8", newline="") as file:
            return [
                {"name": row["name"], "score": int(row["score"])}
                for row in csv.DictReader(file)
            ]
    except FileNotFoundError:
        return []


def summarize(records):
    if not records:
        return {"count": 0, "average": None, "highest": None}
    scores = [record["score"] for record in records]
    return {
        "count": len(scores),
        "average": sum(scores) / len(scores),
        "highest": max(scores),
    }


def main():
    samples = [("Ada", "90"), ("小林", "0"), ("Kai", "cat"), ("Bo", "60")]
    records = []
    for name, text in samples:
        score = parse_score(text)
        if score is not None:
            records.append({"name": name, "score": score})

    path = "gradebook_demo.csv"
    save_records(path, records)
    loaded = load_records(path)
    result = summarize(loaded)
    print(loaded)
    print(f"Records: {result['count']}")
    if result["average"] is None:
        print("Average: N/A")
        print("Highest: N/A")
    else:
        print(f"Average: {result['average']:.2f}")
        print(f"Highest: {result['highest']}")


if __name__ == "__main__":
    main()
```

预期输出：

```text
[{'name': 'Ada', 'score': 90}, {'name': '小林', 'score': 0}, {'name': 'Bo', 'score': 60}]
Records: 3
Average: 50.00
Highest: 90
```

逐步核对：`cat` 转换失败而被排除；`0` 被保留；三个有效成绩总和 `90 + 0 + 60 = 150`，平均分 `150 / 3 = 50.0`。最后统计的是 `loaded`，不是录入列表。

本阶段假设 CSV 由本程序生成、表头为 `name,score` 且记录合法。缺文件返回空列表；损坏表头、缺字段或非法成绩不会被静默吞掉。复杂文件恢复留给后续原计划，不把失败伪装成空账本。

## ⚠️ 易错点

| 写法或误解 | 问题 | 修正 |
| --- | --- | --- |
| `if score:` | 合法的 0 被当成假 | `if score is not None:` |
| 直接对 CSV 字符串成绩求和 | 类型不符合计算需求 | 加载时转换为 `int` |
| 保存后仍统计原列表 | 未证明文件往返正确 | 重新加载后再统计 |
| 对空列表直接除以长度或 `max` | 除零或空序列异常 | 先处理空账本 |
| `return print(result)` | 返回的是 `None`，不是统计字典 | 计算函数 `return`，调用处打印 |
| `except Exception: return []` | 损坏数据、代码错误可能被掩盖 | 只捕获本阶段明确处理的缺文件异常 |

## ✍️ 三项验收练习

### 练习 1：不运行，先解释

为什么 `score = parse_score("0")` 后，`if score` 与 `if score is not None` 的行为不同？

<details><summary>查看答案</summary>

`score` 是整数 0，其布尔值为假；但它不是 `None`，是合法成绩。无效标记与合法数值不能混用。

</details>

### 练习 2：空文件往返

在空测试目录保存空记录列表，再加载并统计。记录数、平均分、最高分应分别是什么？

<details><summary>查看可运行检查</summary>

```python
from gradebook_demo import save_records, load_records, summarize

save_records("empty_demo.csv", [])
assert load_records("empty_demo.csv") == []
assert summarize(load_records("empty_demo.csv")) == {
    "count": 0, "average": None, "highest": None
}
```

CSV 有表头，但没有成绩记录。不要对空数据调用 `max` 或执行除零。

</details>
