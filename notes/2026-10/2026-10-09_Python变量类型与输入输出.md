## 🧠 先理解概念

### 1. 变量：给一个值起名字

Python 通常直接赋值，不用像 Java 的 `int score = 86;` 那样先声明类型。

```python
score = 86
print(score)
score = score + 4
print(score)
```

输出：

```text
86
90
```

`score = score + 4` 的顺序是：读取旧的 `score`（86），算出右边的值（90），再把 `score` 绑定到新值。`=` 在这里是赋值；判断相等会用到 `==`，下一天再练。

**类型属于值。** 同一个变量名可以先绑定整数，再绑定字符串；为了让代码易懂，学习时尽量让一个名字始终表示同一类数据。

```python
value = 86
print(type(value))
value = "86"
print(type(value))
```

输出：

```text
<class 'int'>
<class 'str'>
```

变量名建议用 `student_name`、`average_score`，见名知意。不能用 `2score`，也不要把变量命名为 `input`、`print` 或 `int`，否则会覆盖后面要用的名字。

### 2. 四种常见类型

| 类型 | 表示什么 | 示例 | 今天怎么用 |
| --- | --- | --- | --- |
| `int` | 整数 | `86`、`0`、`-3` | 人数、整数分数 |
| `float` | 浮点数，常用来表示小数 | `86.5`、`0.0` | 平均分、金额 |
| `str` | 字符串，即文字 | `"86"`、`"Ada"` | 姓名、输入的原始文本 |
| `bool` | 真或假 | `True`、`False` | 后续的条件判断 |

`86` 是数字，`"86"` 是文字。看起来相似，能执行的操作不同：

```python
print(86 + 4)
print("86" + "4")
print(type(True))
```

输出：

```text
90
864
<class 'bool'>
```

字符串之间的 `+` 是拼接；数字之间的 `+` 是计算。`"86" + 4` 会报 `TypeError`，Python 不会自动替你选择「算数」还是「拼文字」。

### 3. input：先得到一行文字

`input()` 会等待你输入一行并回车，成功读取时返回 `str`。就算输入的是 `86`，得到的仍是字符串。

```python
raw_score = input("请输入成绩：")
print(type(raw_score))
score = int(raw_score)
print(score + 4)
```

交互示例（`86` 是你键盘输入的内容）：

```text
请输入成绩：86
<class 'str'>
90
```

这一句可以缩写为 `score = int(input("请输入成绩："))`。执行时先运行内部的 `input()`，再运行外部的 `int()`，最后赋值给 `score`。

| 写法 | 作用 | 结果 |
| --- | --- | --- |
| `int("86")` | 整数字符串变成整数 | `86` |
| `float("86.5")` | 数字字符串变成浮点数 | `86.5` |
| `str(86)` | 数字变成文字 | `"86"` |
| `type("86")` | 查看类型，不做转换 | `<class 'str'>` |

`int(raw_score)` 会返回一个转换后的值，**不会改写 `raw_score`**。要保留结果，需要赋值，例如 `score = int(raw_score)`。

注意：`int("86.5")` 不能直接解析小数字符串，会报 `ValueError`。`int(86.5)` 则得到 `86`，是截去小数部分，不是四舍五入。录入可能有小数的成绩时直接用 `float()`。

### 4. 运算：括号和除法

```python
first_score = 80
second_score = 93
print((first_score + second_score) / 2)
print(5 / 2)
print(5 // 2)
```

输出：

```text
86.5
2.5
2
```

- 两门平均分是 `(first_score + second_score) / 2`。去掉括号会先做除法，算成另一件事。
- `/` 是普通除法，两个整数相除也得到 `float`。
- `//` 是向下取整的整除。今天认识即可；计算平均分用 `/`。

## 💻 输出：print 与 f-string

### 1. 多个值可以直接交给 print

```python
name = "Ada"
score = 86
print(name, score)
print(name, score, sep=" | ")
print("A", end="-")
print("B")
```

输出：

```text
Ada 86
Ada | 86
A-B
```

`print()` 默认用空格分隔多个值，并在末尾换行。`sep` 调整分隔文字，`end` 调整末尾文字。

### 2. f-string：把变量填进文字里

```python
name = "Ada"
average = 86.5
print(f"{name} 的平均分：{average:.2f}")
print("平均分：{average:.2f}")
print(average)
```

输出：

```text
Ada 的平均分：86.50
平均分：{average:.2f}
86.5
```

拆开看第一句：

- 引号前的 `f`：启用格式化字符串。
- `{name}`：把变量 `name` 的值放到这里。
- `{average:.2f}`：把平均分按两位小数显示。

**`:.2f` 调整的是显示方式，变量 `average` 仍然是原来的数值。** 显示两位小数时会进行舍入，但浮点数未必精确表示所有十进制小数；今天先掌握这种输出写法。

## 🛠️ 跟着写：两门成绩摘要

把下面代码保存成 `grade_summary.py`，在 Mac 终端进入它所在的文件夹，然后运行 `python3 grade_summary.py`。如果你已用 `uv` 配置项目，也可以使用项目原有的运行方式。


## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 小反例或修正 |
| --- | --- | --- |
| 输入 `18` 就得到整数 | `input()` 返回字符串 | `type(input())` 得到 `str` |
| `"80" + "90"` 等于 170 | 字符串相加是拼接 | 结果是 `"8090"` |
| Python 会自动把字符串转成数字 | 计算前自己选择转换方式 | `int("80") + int("90")` |
| 调用 `int(a)` 后，`a` 已变成整数 | 转换返回新值，要保存它 | `a = int(a)` |
| `int("3.9")` 得到 3 | 这种字符串不是整数形式 | 需要小数时用 `float("3.9")` |
| `int(3.9)` 会四舍五入到 4 | 转为整数时向零截断 | 结果是 `3` |
| 输出 `{score}` 就会替换变量 | 格式化字符串需要前缀 `f` | `print(f"{score}")` |
| `:.2f` 把变量改成两位小数 | 它只控制输出格式 | 显示 `86.50`，数值仍为 `86.5` |
| 两个整数相除一定得到整数 | `/` 与 `//` 有不同含义 | `5 / 2` 是 `2.5` |
| 赋值等同于数学上的等式 | 先算右边，再更新左边 | `score = score + 1` 合法 |
