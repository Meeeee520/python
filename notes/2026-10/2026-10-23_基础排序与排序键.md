## 1. 插入排序的核心

第 i 轮开始前，`0..i-1` 已有序。保存当前记录，从右向左移动比它更小的成绩，最后插入空位。按成绩降序时，只在前项成绩**严格小于**当前成绩时移动；相等时停止，因此原来的相对顺序保留。

最坏情况移动约 n(n−1)/2 项，时间 O(n²)。本文复制输入后排序，所以返回值独立于原列表，额外空间 O(n)。

## 2. Python 自带排序

`sorted(records, key=lambda item: item[1], reverse=True)` 返回新列表，以成绩为键降序排列。Python 排序保证稳定：键相等时保留原相对顺序。`list.sort()` 则原地修改并返回 `None`。项目中优先用自带排序；手写插入排序用于理解算法，不重复造生产轮子。

## 3. 可运行示例

```python
def insertion_sort_by_score(records):
    result = records.copy()
    for i in range(1, len(result)):
        current = result[i]
        j = i - 1
        while j >= 0 and result[j][1] < current[1]:
            result[j + 1] = result[j]
            j -= 1
        result[j + 1] = current
    return result


def main():
    records = [("Amy", 80), ("Bo", 95), ("Cy", 80), ("Di", 70)]
    print(insertion_sort_by_score(records))
    print(sorted(records, key=lambda item: item[1], reverse=True))
    print(records)


if __name__ == "__main__":
    main()
```

两种排序都输出：

```text
[('Bo', 95), ('Amy', 80), ('Cy', 80), ('Di', 70)]
```

最后一行仍是原始 records，说明手写函数与 `sorted` 都没有改动输入。空列表返回空列表；全部同分时保持原顺序。

## ⚠️ 易错点

| 错误 | 纠正 |
| --- | --- |
| 用 `<=` 右移同分记录 | 会破坏这份手写实现的稳定性 |
| 把 `records.sort()` 赋给变量 | 返回值是 None |
| 忘记 key | 元组默认先比姓名，不是成绩 |
| 为简单排序引入新依赖 | 标准库已足够 |
