## 🎯 今日目标

- 理解字典保存的是“键 → 值”关系，键在同一个字典中必须唯一。
- 会创建、读取和修改字典，并用 `in` 判断键是否存在。
- 知道 `records[key]` 与 `records.get(key)` 在键不存在时的区别。
- 会用嵌套字典表示一名学生的姓名和成绩。
- 理解集合会自动去重，空集合必须写成 `set()`。
- 能处理重复学号、存在的查询和不存在的查询。

## 1. 为什么成绩档案更适合用字典

列表擅长按位置保存数据，例如第 0、1、2 个成绩；但查学生时，我们更自然地说“查学号 `S002`”，而不是“查第 1 个元素”。字典让学号直接对应一条记录：

```python
records = {
    "S001": {"name": "Ada", "score": 86},
    "S002": {"name": "Bob", "score": 92},
}

print(records["S001"]["name"])
print(records["S002"]["score"])
```

输出：

```text
Ada
92
```

外层字典的键是学号，值又是一个字典。内层用有含义的键 `name`、`score` 描述同一名学生，这就是简单的数据建模。

## 2. 键必须唯一：先检查，再写入

给已经存在的键重新赋值会覆盖旧值：

```python
records = {"S001": {"name": "Ada", "score": 86}}
records["S001"] = {"name": "Ann", "score": 99}
print(records["S001"])
```

输出 `{'name': 'Ann', 'score': 99}`。如果学号不允许重复，不能等覆盖以后才发现：

```python
student_id = "S001"
if student_id in records:
    print("Duplicate ID")
else:
    records[student_id] = {"name": "Ann", "score": 99}
```

`student_id in records` 检查的是**键**，不是姓名或成绩。

## 3. `[]` 与 `get()`：确定存在，还是可能不存在

```python
records = {"S001": {"name": "Ada", "score": 86}}

print(records["S001"])
print(records.get("S999"))
print(records.get("S999", "Not found"))
```

输出：

```text
{'name': 'Ada', 'score': 86}
None
Not found
```

- `records["S999"]` 会抛出 `KeyError`，适合“这个键按设计一定存在”的情况。
- `records.get("S999")` 在不存在时返回 `None`。
- `records.get("S999", 默认值)` 可以返回自定义默认值。

查找结果可能是 `None` 时，用 `is None` 判断最清楚。

## 4. 集合：只关心“出现过没有”

集合不保存重复元素，很适合记录已经见过的学号：

```python
seen_ids = set()
for student_id in ["S001", "S002", "S001"]:
    if student_id in seen_ids:
        print("Duplicate:", student_id)
    else:
        seen_ids.add(student_id)

print(len(seen_ids))
```

输出：

```text
Duplicate: S001
2
```

注意：`{}` 是空字典，空集合必须写 `set()`。集合无序，不要把它的打印顺序当作固定答案。

## 5. 把增添与查询写成函数

昨天学过的函数可以让职责更清楚：

```python
def add_student(records, seen_ids, student_id, name, score):
    if student_id in seen_ids:
        return False
    records[student_id] = {"name": name, "score": score}
    seen_ids.add(student_id)
    return True


def find_student(records, student_id):
    return records.get(student_id)


records = {}
seen_ids = set()

print(add_student(records, seen_ids, "S001", "Ada", 86))
print(add_student(records, seen_ids, "S001", "Ann", 99))
print(find_student(records, "S001"))
print(find_student(records, "S999"))
```

输出：

```text
True
False
{'name': 'Ada', 'score': 86}
None
```

失败的重复添加没有覆盖第一条记录。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| `{}` 是空集合 | `{}` 创建空字典 | 空集合写 `set()` |
| 字典可以同时保存两个相同键 | 同一个键再次赋值会覆盖旧值 | 写入前用 `key in records` 检查 |
| `x in records` 检查所有值 | 默认只检查字典的键 | 查值需明确遍历或使用 `values()` |
| `records[key]` 查不到会返回 `None` | 它会抛出 `KeyError` | 可能不存在时使用 `get()` |
| 集合打印顺序固定 | 集合是无序集合 | 不用打印顺序作为测试答案 |
| 嵌套字典必须写成很多平行列表 | 一条记录可以用一个内层字典表示 | 用 `records[id]["score"]` 读取 |
