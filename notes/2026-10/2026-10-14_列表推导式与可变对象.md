## 1. 列表推导式：把“筛选并收集”写在一行

先看普通循环：

```python
scores = [86, 55, 72, 90]
passed = []
for score in scores:
    if score >= 60:
        passed.append(score)

print(passed)
```

列表推导式把同一逻辑写成：

```python
scores = [86, 55, 72, 90]
passed = [score for score in scores if score >= 60]
print(passed)
```

两段代码都输出：

```text
[86, 72, 90]
```

阅读顺序可以记成：

1. `for score in scores`：逐个取元素；
2. `if score >= 60`：只保留满足条件的元素；
3. 最前面的 `score`：决定新列表里放什么。

列表推导式会创建一个**新的外层列表**，但这不保证里面的可变对象也被复制。

## 2. 赋值不是复制：两个名字可以指向同一个列表

```python
scores = [86, 72]
backup = scores
backup[0] = 0

print(scores)
print(backup)
```

输出：

```text
[0, 72]
[0, 72]
```

`backup = scores` 只是给同一个列表再起一个名字。通过任意一个名字修改列表，另一个名字看到的也是修改后的对象。

如果列表中只有整数、字符串等不可变值，可以复制外层列表：

```python
scores = [86, 72]
backup = scores.copy()
backup[0] = 0

print(scores)
print(backup)
```

输出：

```text
[86, 72]
[0, 72]
```

## 3. 浅拷贝：外层分开，内部记录仍可能共享

```python
records = [{"name": "Ada", "score": 86}]
backup = records.copy()
backup[0]["score"] = 0

print(records[0]["score"])
```

输出 `0`。原因是 `records.copy()` 只新建了外层列表，两个列表的第 0 项仍指向同一个字典。

对于“列表中每项都是一层简单字典”的成绩记录，可以逐项复制：

```python
records = [
    {"name": "Ada", "score": 86},
    {"name": "Bob", "score": 55},
]

backup = [record.copy() for record in records]
backup[0]["score"] = 0

print(records[0]["score"])
print(backup[0]["score"])
```

输出：

```text
86
0
```

如果字典里面还套着列表或字典，逐项 `copy()` 仍是浅拷贝；只有确实需要把所有嵌套可变对象都分开时，才考虑 `copy.deepcopy()`。

## 4. 二维列表的共享行陷阱

下面写法看似创建三行，其实把**同一个行对象**重复放了三次：

```python
grid = [[0] * 3] * 3
grid[0][1] = 9
print(grid)
```

输出：

```text
[[0, 9, 0], [0, 9, 0], [0, 9, 0]]
```

每次循环都创建一行，才能让三行彼此独立：

```python
grid = [[0] * 3 for _ in range(3)]
grid[0][1] = 9
print(grid)
```

输出：

```text
[[0, 9, 0], [0, 0, 0], [0, 0, 0]]
```

## 5. 综合示例：筛选并制作独立记录

```python
def select_and_copy(records, minimum):
    return [record.copy() for record in records
            if record["score"] >= minimum]


records = [
    {"name": "Ada", "score": 86},
    {"name": "Bob", "score": 55},
    {"name": "Cai", "score": 72},
]

selected = select_and_copy(records, 60)
selected[0]["score"] = 100

print(selected)
print(records)
```

输出：

```text
[{'name': 'Ada', 'score': 100}, {'name': 'Cai', 'score': 72}]
[{'name': 'Ada', 'score': 86}, {'name': 'Bob', 'score': 55}, {'name': 'Cai', 'score': 72}]
```

推导式既完成筛选，也为每条入选记录创建了新字典，因此修改 `selected` 不会改动原记录。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| `backup = records` 会复制列表 | 赋值只增加一个指向同一对象的名字 | 需要新外层时用 `records.copy()` |
| 外层 `copy()` 后所有内容都独立 | 浅拷贝仍共享内部可变对象 | 简单字典可逐项 `record.copy()` |
| 推导式里的 `if` 放在最前面 | 筛选条件写在 `for` 后面 | `[x for x in data if condition]` |
| `[[0] * 3] * 3` 有三条独立行 | 它重复引用同一行 | `[[0] * 3 for _ in range(3)]` |
| 遇到复制一律使用 `deepcopy` | 深拷贝可能复制过多 | 先判断数据嵌套层次与共享需求 |
| 推导式越长越高级 | 可读性比少一行代码重要 | 复杂分支改用普通循环 |
