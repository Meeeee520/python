## 1. 为什么要写函数

没有函数时，同一段平均分代码可能复制很多遍。函数把一项明确工作命名，调用时只需要提供数据：

```python
def average(scores):
    if not scores:
        return None
    return sum(scores) / len(scores)

print(average([60, 80, 100]))
print(average([]))
```

输出：

```text
80.0
None
```

`def average(scores):` 中的 `scores` 是参数；调用 `average([60, 80, 100])` 时，列表是实参。

## 2. `return` 与 `print` 不是一回事

```python
def show_double(x):
    print(x * 2)

def get_double(x):
    return x * 2

a = show_double(5)
b = get_double(5)
print(a)
print(b)
```

输出：

```text
10
None
10
```

- `print` 只把内容显示在屏幕上。
- `return` 把值交回调用位置，并立即结束本次函数调用。
- `show_double` 没写返回值，所以 `a` 是 `None`。

## 3. 参数、实参与多个返回值

```python
def describe(scores):
    if not scores:
        return None
    return min(scores), max(scores), sum(scores) / len(scores)

result = describe([70, 90, 80])
if result is not None:
    lowest, highest, average = result
    print(lowest, highest, average)
```

输出 `70 90 80.0`。Python 用一个元组装下多个返回值，再通过多个变量拆包。

## 4. 局部变量与职责

```python
def total_score(scores):
    total = 0
    for score in scores:
        total += score
    return total

print(total_score([10, 20]))
# print(total)  # NameError
```

`total` 在函数调用时创建，函数外不能直接使用。把录入留在主程序、把计算放进函数，更容易用不同数据测试：

```python
def summarize(scores):
    if not scores:
        return None

    total = 0
    highest = scores[0]
    lowest = scores[0]
    passed = 0

    for score in scores:
        total += score
        if score > highest:
            highest = score
        if score < lowest:
            lowest = score
        if score >= 60:
            passed += 1

    return total / len(scores), highest, lowest, passed
```

正常输入 `[60, 80, 100]` 返回 `(80.0, 100, 60, 3)`；空列表返回 `None`，避免访问 `scores[0]` 和除以 0。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 修正 |
| --- | --- | --- |
| 参数和实参是同一个概念 | 参数是定义中的名字，实参是调用时的值 | `def f(x)` 与 `f(3)` |
| `print(result)` 等同于返回 | 打印不会把值交给调用方 | 使用 `return result` |
| `return` 后面的代码还会执行 | `return` 立即结束本次调用 | 把必要代码放在它之前 |
| 没写 `return` 就没有返回值 | 实际返回 `None` | 调用方可用 `is None` 检查 |
| 函数必须自己 `input()` | 计算函数最好接收参数 | 输入方式可以独立改变 |
| 空列表可以直接求最值 | `min([])`、`scores[0]` 会失败 | 先判断 `if not scores` |
| 函数内变量一定能在外部使用 | 普通局部变量只在函数内有效 | 通过 `return` 交出结果 |

```python
def add_one(x):
    x += 1
    return x

number = 5
print(add_one(number))
print(number)
```

### 练习 3 · 写及格人数函数

编写 `count_passed(scores)`，返回不低于 60 的成绩个数；空列表应返回 0。

<details><summary>查看参考答案</summary>

```python
def count_passed(scores):
    count = 0
    for score in scores:
        if score >= 60:
            count += 1
    return count
```

</details>
