## 🧵 一、字符串：有顺序的字符序列

```python
word = "Python"
print(word[0])
print(word[-1])
print(word[1:5])
print(word[::-1])
```

输出：

```text
P
n
ytho
nohtyP
```

下标从 0 开始；负下标从末尾开始，`-1` 是最后一个字符。切片的一般形式是 `sequence[start:stop:step]`：

- 包含 `start`，不包含 `stop`。
- 省略 `start` 表示从开头，省略 `stop` 表示到末尾。
- `step` 为 `-1` 时可以反向读取。
- 普通切片超出边界通常会自动截到有效范围；单个下标越界则会报 `IndexError`。

字符串不能原地修改：

```python
name = "Ada"
# name[0] = "E"  # TypeError
name = "E" + name[1:]
print(name)
```

输出 `Eda`。这里不是修改原字符串，而是创建新字符串后重新赋值。

## 📋 二、列表：可以修改的有序容器

```python
scores = [78, 92]
scores.append(85)
scores[0] = 80

print(scores)
print(len(scores))
print(scores[-1])
```

输出：

```text
[80, 92, 85]
3
85
```

| 写法 | 作用 |
| --- | --- |
| `scores.append(90)` | 在末尾加入一个元素 |
| `len(scores)` | 得到元素个数 |
| `scores[i]` | 读取第 `i` 个位置 |
| `scores[i] = 90` | 修改第 `i` 个位置 |
| `scores[a:b]` | 取出从 `a` 到 `b` 前一位的新列表 |

空列表 `[]` 的长度为 0，不能访问 `[0]` 或 `[-1]`：

```python
if not scores:
    print("No data")
else:
    print(scores[0])
```

## ✂️ 三、用 `split` 拆开，用 `join` 拼回

```python
line = "Ada 78 92 85"
parts = line.split()

name = parts[0]
score_texts = parts[1:]
scores = []
for text in score_texts:
    scores.append(int(text))

print(name)
print(scores)
print(" | ".join(score_texts))
```

输出：

```text
Ada
[78, 92, 85]
78 | 92 | 85
```

不传参数的 `split()` 会按连续空白拆分，因此多余空格不会产生空字符串。`join()` 的成员必须是字符串；整数列表不能直接 `" ".join(scores)`。

## 🧪 四、完整示例：解析一行成绩并生成摘要

```python
line = input().strip()

if not line:
    print("No data")
else:
    score_texts = line.split()
    scores = []
    for text in score_texts:
        scores.append(int(text))

    backup = scores[:]
    print(f"Count: {len(scores)}")
    print(f"First: {scores[0]}")
    print(f"Last: {scores[-1]}")
    print(f"Middle: {scores[1:-1]}")
    print(f"Reversed: {scores[::-1]}")

    scores[0] = 0
    print(f"Backup first: {backup[0]}")
```

输入 `70 80 90 100` 时输出：

```text
Count: 4
First: 70
Last: 100
Middle: [80, 90]
Reversed: [100, 90, 80, 70]
Backup first: 70
```

`backup = scores[:]` 创建新的外层列表。本例元素都是整数，因此修改 `scores[0]` 不会影响副本。如果只写 `backup = scores`，两个变量指向同一个列表。嵌套可变列表的浅拷贝问题会在 10 月 14 日专门学习。

## ⚠️ 易错点辨析

| 常见误解 | 正确理解 | 小反例 |
| --- | --- | --- |
| 第一个元素下标是 1 | 下标从 0 开始 | `"abc"[0]` 是 `a` |
| 切片包含右端点 | `stop` 不包含 | `[0,1,2][0:2]` 是 `[0,1]` |
| 单个下标和切片越界效果相同 | 下标越界报错，切片会截断 | `[1,2][0:99]` 可用 |
| 字符串能像列表一样改字符 | 字符串不可变 | `s[0] = "A"` 报错 |
| `split()` 返回字符串 | 它返回字符串列表 | `"a b".split()` 是 `["a", "b"]` |
| `join()` 能直接拼整数 | 成员必须是字符串 | 先把整数转换为字符串 |
| `backup = scores` 是复制 | 它只是多一个别名 | 修改任一变量都能看到变化 |
| 空列表也能访问 `[-1]` | 空列表没有有效下标 | 先检查 `if not scores` |

<summary>查看答案</summary>

### 练习 3 · 首尾交换

读入一行空格分隔的单词。若少于两个单词，原样输出列表；否则交换首尾元素并输出列表。

<details>
<summary>查看参考答案</summary>

```python
words = input().split()
if len(words) >= 2:
    words[0], words[-1] = words[-1], words[0]
print(words)
```

空输入得到 `[]`，单个单词保持不变。

</details>
