# 🛠️ 成绩筛选器与安全备份

> 项目 ID：`daily-2026-10-14` · Python 主项目 · 建议用时 45–60 分钟

## 项目目标

读取学生姓名与成绩，按最低分筛选记录；在筛选结果里预览“每人加 1 分”，同时保证原记录和备份完全不变。

今天真正要练的不是“少写几行”，而是分清三件事：

1. `backup = records` 只增加一个名字；
2. `records.copy()` 只复制外层列表；
3. `[record.copy() for record in records]` 能让一层字典记录彼此独立。

## 输入与输出

输入：

```text
3
Ada 86
Bob 55
Cai 72
60
```

依次表示记录数、每条 `姓名 成绩`、最低筛选分数。输出：

```text
Selected: Ada 87, Cai 73
Original: Ada 86, Bob 55, Cai 72
Backup: Ada 86, Bob 55, Cai 72
```

`Selected` 是加 1 分后的预览；`Original` 和 `Backup` 应保持原值。

5. 运行正常、无人达标、零条记录和 100 分边界样例。

<details><summary>提示：为什么不能只用 records.copy()</summary>

它会创建新的外层列表，但列表里的每个字典仍与原列表共享。修改 `selected[0]["score"]` 时，原字典也会改变。

## 参考实现

<details><summary>完成后再展开</summary>

```python
def copy_records(records):
    return [record.copy() for record in records]


def select_records(records, minimum):
    return [record.copy() for record in records
            if record["score"] >= minimum]


def format_records(records):
    if not records:
        return "None"
    return ", ".join(
        f"{record['name']} {record['score']}" for record in records
    )


n = max(0, int(input()))
records = []
for _ in range(n):
    name, score_text = input().split()
    records.append({"name": name, "score": int(score_text)})
minimum = int(input())

backup = copy_records(records)
selected = select_records(records, minimum)
for record in selected:
    record["score"] = min(100, record["score"] + 1)

print("Selected: " + format_records(selected))
print("Original: " + format_records(records))
print("Backup: " + format_records(backup))
```

</details>
