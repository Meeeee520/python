## 复杂度与常见错误

查找计数紧邻比较，命中即返回。

增长实验分别计数，不把三种复杂度误认为同一个查找算法。

完整实验总体O(n²)，额外空间O(1)，输入列表另算。

不要用列表长度代替提前返回时的实际次数；不要将成对循环运行的大规模输入误当成性能优化。

<details><summary>参考实现（独立尝试后打开）</summary>

```python
def find_count(scores, target):
    checks = 0
    for i, score in enumerate(scores):
        checks += 1
        if score == target:
            return i, checks
    return -1, checks


def growth_counts(n):
    if n < 0:
        raise ValueError("n must be nonnegative")
    linear = 0
    pairs = 0
    halves = 0
    for _ in range(n):
        linear += 1
    for i in range(n):
        for _ in range(i + 1, n):
            pairs += 1
    remaining = n
    while remaining > 1:
        remaining //= 2
        halves += 1
    return linear, pairs, halves


def main():
    scores = [int(part) for part in input().split()]
    target = int(input())
    index, checks = find_count(scores, target)
    linear, pairs, halves = growth_counts(len(scores))
    print(f"Index: {index}")
    print(f"Checks: {checks}")
    print(f"Counts: {linear} {pairs} {halves}")


if __name__ == "__main__":
    main()

```
