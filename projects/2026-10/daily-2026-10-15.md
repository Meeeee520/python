# 🛠️ 不会轻易崩溃的录入器

> 项目 ID：`daily-2026-10-15` · Python 主项目 · 建议用时 45–60 分钟

## 项目目标

持续读取一行成绩，分别识别空输入、非整数和越界；遇到错误给出明确提示并继续，直到接受 0 到 100 的整数。

今天最关键的设计是把任务拆成两层：

- `parse_score(text)` 只负责解释一段文本；
- `read_score()` 负责反复读取，直到解析成功。

## 运行示例

依次输入：

```text
cat
105
86
```

输出：

```text
Invalid: Not an integer
Invalid: Out of range
Accepted: 86
```

## 分步完成

1. `strip()` 后先处理空字符串。
2. 只把 `score = int(text)` 放进 `try`，捕获 `ValueError`。
3. 转换成功后检查 `0 <= score <= 100`。
4. `read_score` 用 `while True` 重试；成功条件必须写 `value is not None`。
5. 验证空行、`cat`、`86.5`、`-1`、`0`、`100` 和 `105`。

<details><summary>提示：为什么不能写 if value</summary>

成绩 `0` 是合法的，但 `bool(0)` 为 `False`。因此必须用 `value is not None` 判断解析是否成功。

</details>

## 参考实现

<details><summary>完成后再展开</summary>

```python
def parse_score(text):
    text = text.strip()
    if not text:
        return None, "Empty input"

    try:
        score = int(text)
    except ValueError:
        return None, "Not an integer"

    if not 0 <= score <= 100:
        return None, "Out of range"
    return score, "OK"


def read_score():
    while True:
        value, message = parse_score(input())
        if value is not None:
            return value
        print("Invalid: " + message)


score = read_score()
print(f"Accepted: {score}")
```

</details>

## 自测重点

- 第一次输入合法时，不应先打印错误。
- 连续错误时，每次提示应与原因对应。
- 空行不能产生未处理的 `ValueError`。
- `0` 和 `100` 都必须被接受。
