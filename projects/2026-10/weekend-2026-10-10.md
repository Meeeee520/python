## 分步任务

### 2026-10-10 · 让程序读到一组成绩

- [ ] 先写 n = int(input())。n <= 0 时输出“暂无成绩”；其余情况用 for i in range(n) 逐个读入浮点数。先用 3、60、80、100 试运行。

**为什么 / 提示**：input 得到字符串；int/float 决定如何把它变成数字。range(n) 恰好循环 n 次。

**会用到**：input、类型转换、for/range

### 2026-10-10 · 在循环里累积统计量

- [ ] 为 total、highest、lowest、passed 安排初值。每读到一个合法成绩就更新这四个变量。平均分在循环结束后算；60 分也算及格。

**为什么 / 提示**：合法分数在 0–100 内，因此最高分可以从 0 开始、最低分从 100 开始。不要把 total / n 放进 n <= 0 的分支。

**会用到**：累加、if、边界

### 2026-10-10 · 给越界成绩一次重试机会

- [ ] 成绩小于 0 或大于 100 时输出 Invalid input，并在 while 中重读，直到合法。今天假定输入是数字，不要求提前学习 try/except。

**为什么 / 提示**：重试属于同一个学生；只有离开 while 后才进入下一轮 for。

**会用到**：while、逻辑 or、输入范围

### 2026-10-11 · 把成绩留下来，支持再次分析

## 合上笔记，再说一遍

- 为什么要先处理 n <= 0，再计算 total / n？
- 为什么 range(n) 不会读 n + 1 次成绩？
- backup = scores 和 backup = scores[:] 的差别是什么？

```python
n = int(input())
if n <= 0:
    print("暂无成绩")
else:
    scores = []
    for i in range(n):
        score = float(input())
        while score < 0 or score > 100:
            print("Invalid input")
            score = float(input())
        scores.append(score)

    total = 0
    highest = scores[0]
    lowest = scores[0]
    passed = 0
    for score in scores:
        total += score
        if score > highest:
            highest = score
        if score < lowest:
            lowest = score
        if score >= 60:
            passed += 1

    backup = scores[:]
    print(f"平均分：{total / n:.2f}")
    print(f"最高分：{highest:.2f}")
    print(f"最低分：{lowest:.2f}")
    print(f"及格人数：{passed}/{n}")
    # 周日实验：在本地临时加入 scores[0] = 0 与 print(backup[0])。
    # 一维列表副本应保留修改前的数值；实验后移除额外输出再跑自测。
```

- 输入阶段先校验人数和成绩范围；任何非法成绩都在同一轮重试。
- 统计阶段只处理已收集的合法成绩，每个变量只承担一种职责。
- 输出阶段统一保留两位小数，避免把字符串拼接与数值计算混在一起。
- 周六版本可以直接边输入边统计；参考代码展示周日完成后的列表版本。
