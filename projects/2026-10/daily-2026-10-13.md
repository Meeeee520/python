## 要做出什么

按学号保存姓名和成绩，拒绝重复学号，并能查询存在或不存在的学生。第一条同学记录不能被重复输入覆盖。

输入格式：

1. 第一行是记录条数 `n`。
2. 接下来 `n` 行是 `学号 姓名 成绩`，姓名暂不含空格。
3. 最后一行是要查询的学号。

今天先假定人数和成绩都是合法数字；非数字与范围校验会在异常处理学习日加入。

## 分步任务

### 1. 设计一条学生记录

- [ ] 用学号作为外层字典的键，用 `{"name": 姓名, "score": 成绩}` 作为值。先手写两条记录并读取其中一名学生的成绩。

**为什么 / 提示**：目标结构是 `records[student_id]["score"]`，不再维护容易错位的平行列表。

**会用到**：`dict`、嵌套记录、键值关系。

### 2. 拒绝重复学号

- [ ] 完成 `add_student`。`seen_ids` 使用 `set()` 创建；学号出现过就返回 `False`，不写入 `records`，保证第一条记录不被覆盖。

**会用到**：`set`、成员检查、唯一键。

### 3. 安全查询存在与不存在的学生

## 合上笔记，再说一遍

- 为什么学号适合做 `records` 的键，而姓名不一定适合？
- 为什么查询函数使用 `get` 而不直接写 `records[student_id]`？
- 为什么 `seen_ids` 不能写成 `{}`？

<summary>完成后再打开：参考实现与解释</summary>

```python
def add_student(records, seen_ids, student_id, name, score):
    if student_id in seen_ids:
        return False
    records[student_id] = {"name": name, "score": score}
    seen_ids.add(student_id)
    return True


def find_student(records, student_id):
    return records.get(student_id)


count = int(input())
records = {}
seen_ids = set()
for _ in range(max(0, count)):
    student_id, name, score_text = input().split()
    score = float(score_text)
    if not add_student(records, seen_ids, student_id, name, score):
        print(f"Duplicate: {student_id}")

query_id = input().strip()
student = find_student(records, query_id)
print(f"Students: {len(records)}")
if student is None:
    print(f"Not found: {query_id}")
else:
    print(f"{query_id} {student['name']} {student['score']:.2f}")
```

- 外层字典让学号直接对应一条学生记录，内层字典用有含义的键保存姓名和成绩。
- 添加前检查集合，重复学号立即返回，避免字典赋值覆盖旧记录。
- 查询使用 `get`，让不存在的学号成为正常分支而不是异常。

</details>
