## 目标

用稳定插入排序与 Python 内置排序生成同一排行榜，解释 key 与稳定性。

## 步骤

1. **保护输入**：先复制records，不原地修改调用者列表。

2. **维护有序前缀**：从第1项起，将更小成绩向右移动。

3. **守住稳定性**：同分时不移动，保留原相对顺序。

4. **与内置排序对照**：使用sorted、key和reverse核对结果。

## 参考实现

<details><summary>独立尝试后查看</summary>

```python
def insertion_sort_by_score(records):
    result = records.copy()
    for i in range(1, len(result)):
        current = result[i]
        j = i - 1
        while j >= 0 and result[j][1] < current[1]:
            result[j + 1] = result[j]
            j -= 1
        result[j + 1] = current
    return result


def main():
    records = [("Amy", 80), ("Bo", 95), ("Cy", 80), ("Di", 70)]
    print(insertion_sort_by_score(records))
    print(sorted(records, key=lambda item: item[1], reverse=True))
    print(records)


if __name__ == "__main__":
    main()
```
