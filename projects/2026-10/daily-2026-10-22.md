## 目标

实现并比较线性查找与闭区间二分查找，验证有序前提和边界。

## 步骤

1. **写返回契约**：两种查找都返回下标与实际比较次数，未命中返回-1。

2. **实现线性查找**：逐项比较，首个命中立即返回。

3. **实现二分查找**：仅对升序互异列表维护闭区间low/high。

4. **运行边界**：检查空、单元素、首尾和未命中。

## 参考实现

```python
def linear_search(values, target):
    checks = 0
    for i, value in enumerate(values):
        checks += 1
        if value == target:
            return i, checks
    return -1, checks


def binary_search(values, target):
    low, high = 0, len(values) - 1
    checks = 0
    while low <= high:
        mid = (low + high) // 2
        checks += 1
        if values[mid] == target:
            return mid, checks
        if values[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1, checks


def main():
    values = [int(x) for x in input().split()]
    target = int(input())
    linear = linear_search(values, target)
    binary = binary_search(values, target)
    print("Linear:", *linear)
    print("Binary:", *binary)


if __name__ == "__main__":
    main()
```
