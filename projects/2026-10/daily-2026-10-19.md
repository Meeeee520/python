用同一份 Python 成绩报告依次练习计数、增加平均分、修复空输入，实际测试后留下三次本地 Git 提交；不推送、不操作原网站或现有公开仓库。

## 目标与先修

- 函数、列表、main 入口与空数据处理
- 今日笔记：Git 工作区、暂存区、提交、status/diff/log

## 起始代码

```python
def main():
    scores = [int(part) for part in input().split()]
    print(f"Count: {len(scores)}")

if __name__ == "__main__":
    main()
```

## 分步任务

### 1. 在新目录记录计数版本

新建独立空练习目录，初始化 Git；用起始代码检查非空、空行均输出正确数量，然后按文件暂存并提交 feat: count scores。

提示：只在这个新目录配置练习身份；不要改全局配置，不添加 remote。

### 2. 增加非空平均分

将报告计算提取成 report(scores)，先支持非空数据；查看工作区与暂存区差异，提交 feat: add average。

提示：每次编辑后都要保存，暂存后再编辑需要重新 add。

### 3. 用边界测试推动第三次提交

空输入暴露除零问题；先处理空列表，再用正常、空与 0 分测试确认，提交 fix: handle empty scores。

提示：空输入与只有一个 0 的输入不能混为一谈。

### 4. 解释本地历史

使用 git log -3 --format=%s 核对三条说明；再确认短状态干净。只在实际完成后记录进度。

提示：提交 SHA 不必与别人相同；不执行 push。

## 常见错误

- 把后续保存当作自动重新暂存：需要再次 git add。
- 只看普通 diff，忽略暂存区：两种 diff 分别检查。
- 一次暂存全部文件：本练习使用明确路径，避免无关数据。
- 以为 commit 会上传 GitHub：今天只记录本地历史。

## 参考实现

<details><summary>独立完成并自测后再展开</summary>

```python
def report(scores):
    if not scores:
        return "Count: 0\nAverage: N/A"
    return f"Count: {len(scores)}\nAverage: {sum(scores) / len(scores):.2f}"


def main():
    scores = [int(part) for part in input().split()]
    print(report(scores))


if __name__ == "__main__":
    main()
```

- 计数、平均分、空输入处理分成三次有目的的改动。
- 最终 report 是只返回字符串的计算函数，main 负责读取和打印。
- 空列表先返回 N/A；合法 0 正常参与统计。
- Git 操作只在新的本地训练目录进行；命令与三版代码见同名 Markdown。

</details>
